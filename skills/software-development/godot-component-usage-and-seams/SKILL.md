# Godot 2D 组件使用指导与贴图缝隙处理规范

本 Skill 规范了在向用户解释 2D 可复用组件（如滚动水面、背景、视差层）用法时的沟通原则，以及处理 2D 贴图拼接与滚动缝隙的标准技术方案。

---

## 一、 用户沟通与答疑原则 (Communication Principles)

1. **先讲清楚用法，严禁在用户询问机制时擅自改代码**：
   - 当用户询问“怎么用”、“在一个大场景里用一个还是铺满”时，**首要任务是明确答复设计意图与操作步骤**。
   - 严禁把用户的疑问当成修改指令去盲目重构底层实现，造成用户认知混乱和抵触。
   - 明确回答核心问题：组件是单例覆盖（一个节点配尺寸/平铺）还是散件拼接（拼图式摆放）。

2. **交付组件时先证明“设计师能找到并摆起来”**：
   - 实现前先定义唯一入口：用户应打开哪个宿主场景、在场景树展开哪一条节点路径、哪些节点已经实例化、哪些才需要用户自行拖入。不要把源码目录、资源清单或参数表当成使用说明。
   - 默认给最短操作路径，按“打开宿主场景 → 选中目标节点 → 在 2D 视口移动/缩放 → 复制或拖入新实例”的顺序写；用户追问前不要同时讲内部脚本、素材裁切、视差公式和全部文件。
   - 若节点来自实例化场景，必须实际验证编辑器内能否展开和编辑子节点；需要时明确使用“可编辑子项”或让用户打开原组件场景编辑，不能只说“展开后直接改”。
   - 为散件拼景保留清晰、少量、可命名的示例，不要一次生成大量相似节点而没有分组、编辑说明或视觉锚点；节点数量多会让场景树变成新的认知负担。
   - 完成后用真实宿主场景做一次“设计师路径”验收：找到入口、移动一个现有装饰、复制一个装饰到固定砖块、把一个装饰挂到移动平台并确认跟随。运行测试通过不等于组件会用。
   - 回报先用一句话说明“生成了什么、现在在哪里、用户下一步点哪里”；技术验证和文件列表放到后面，避免用户面对大量产物仍不知道入口。

3. **区分编辑器静态预览与运行期动态特性**：
   - `Parallax2D` / `ParallaxBackground` 的 `autoscroll` 默认只在游戏运行期（F5/F6）驱动，在 Godot 编辑器视口中是静态不动的。
   - 若用户需要“在编辑器中即时看到流动效果”，应向用户说明原因，并在需要时采用 `@tool` 脚本或 Shader（`TIME` / UV offset）方案。

4. **先锁定“尺寸变化影响谁”，再设计节点层级**：
   - 对可拉伸的区域组件，逐项确认逻辑范围、碰撞、转换后贴图、转换前 TileMap 是否应继承根节点缩放；不要把“同属一个组件”误解为“必须共享同一缩放”。
   - 用户只要求统一 TileSet 保持原始砖格时，只解决变换隔离；不要扩大为自动铺砖、扫描邻块、动态匹配纹理、计算格数或重建碰撞。
   - 转换前视觉应是开放容器：砖块可由设计师在统一 TileMap 中自由编辑；尺寸、锚点或法线材质不适合 TileSet 单元的纯视觉符文应使用并列的 `Sprite2D`，不要为塞进 TileMap 而重建图集或改变砖格。其他纯视觉节点也可并列加入，但不得额外承担交互逻辑。
   - 符文若只是“可转换”的视觉提示，就不得为其增加独立点击、碰撞、目标检测或逻辑锚点；交互仍由原矩形区域承担。

### 可拉伸逻辑区域与不拉伸 TileMap 的处理顺序

1. 先检查现有实例如何改变范围：是根节点 `scale`、显式 `area_size`，还是子节点尺寸覆写；同时记录继承场景中的节点覆写，避免迁移时丢失既有物理参数。
2. 把需拉伸的碰撞/范围/转换后整图与不应拉伸的转换前视觉视为两个变换分支。优先做结构性隔离；若必须保留根节点缩放，则只在专用派生组件中抵消转换前视觉继承到的缩放。
3. TileMap 继续使用项目统一 TileSet 和设计师已有布局；不要因纹理源尺寸或 TileMap 自身导入缩放再建立一套运行时网格系统。
4. 转换后完整贴图可按逻辑矩形拉伸并挂 Shader；转换前 TileMap 只跟随位置和旋转，砖格比例保持不变。
5. 在编辑器和运行时各验证一次非均匀缩放：确认碰撞与转换后贴图改变尺寸，而 TileMap 单格的世界宽高不变；再实例化真实宿主场景，检查继承覆写与节点路径未失效。

**Pitfall — 不要用未经验证的局部逆缩放公式直接交付**：祖先层级、旋转、负缩放和编辑器所有权都会影响最终变换；必须以真实实例的 `global_transform` 或单格世界尺寸断言验证“只跟随位置/旋转、不跟随拉伸”。

## 二、 2D 滚动水体/平铺拼接缝隙解决方案 (Seam & Overlap Solutions)

在 2D 游戏中，当半透明或带光效（焦散、光柱）的滚动表层与静态下层水体拼接时，经常出现水平横切缝或深色重叠块。

### 1. 产生机理
- **半透明 Alpha 叠加变暗**：贴图本身带有 Alpha 通道时，若上下两层 Sprite/TextureRect 发生 1 像素以上的几何重叠，Alpha Blend 混合会导致重叠区域颜色明显发暗变深。
- **硬切边与视觉截断**：竖向焦散光条在表层组件的底部被硬性截断（没有平滑羽化），与下层水体顶部拼接时产生刺眼的阶梯断层。
- **透出背景**：若未完全贴合，只要有微小空隙就会透出底色。

### 2. 严禁改动尺寸/缩放的无损修复方案：Shader 边缘羽化 (Shader Edge Fade)
在用户明确要求“不改变组件/Scroll 尺寸”的前提下，**绝对不要通过调整节点缩放、修改 Y 轴尺寸或拉伸贴图来对齐**。

**标准解法**：在水面 Shader 的 `fragment()` 中加入底部或边缘的归一化软过渡遮罩（Fade Out）。

```glsl
shader_type canvas_item;

uniform float offset_x = 0.0;
uniform float bottom_fade_ratio : hint_range(0.01, 0.5) = 0.1; // 底部羽化区间比例

void fragment() {
    vec2 uv = UV;
    uv.x = fract(uv.x + offset_x);
    vec4 col = texture(TEXTURE, uv);
    
    // 底部边缘软羽化：消除与下方图块接触处的硬切边与半透明叠加深色块
    float bottom_fade = clamp((1.0 - uv.y) / bottom_fade_ratio, 0.0, 1.0);
    col.a *= bottom_fade;
    
    COLOR = col;
}
```

- **效果**：表层贴图在接触下层水体前 10% 区域的 Alpha 平滑衰减到 0，不仅抹平了竖向光柱的横切硬线，而且即使有小范围的几何重叠也不会产生突兀的深色色块，实现自然融合。

## 三、 视差背景接缝与纵向无缝拼接 (Parallax Background & Vertical Looping)

在 Godot 4 的 2D 视差背景（基于 `Parallax2D` 或双图镜像 `dual-sprite-mirror`）中，常见两类拼接缺陷：
1. **接缝漏底细线**（通常为 1 像素底色细线，即漏出 Viewport Clear Color，例如 `(77, 77, 77)`）；
2. **纵向跳跃断层**（摄像机垂直移动、角色大跳跃时天空或背景截断露底）。

### 1. 接缝漏底细线成因与 1px 安全重叠规范
- **成因**：原 Sprite 与水平镜像 Sprite（`flip_h = true`）在理论坐标对接处（如 $X=W$）虽然完全对齐，但在运行时经过 `layer.scale`、场景实例缩放和相机的连续浮点变换后，GPU 光栅化插值会产生亚像素舍入误差，相邻 Quad 之间瞬间产生 1 像素空隙，漏出底层视口清除色（Clear Color）。
- **标准解法**：
  - **镜像节点 1 像素安全内嵌重叠**：将对接侧 Sprite 节点坐标朝内微调 1 像素（例如原图宽 $W$，镜像 Sprite 坐标由 $W$ 改为 $W - 1$）。
  - **周期补偿**：双图水平镜像的总循环宽度对应微调为 $2W - 2$（或 $2W - 1$），同步更新 `Parallax2D.repeat_size.x`。由于镜像对接处的像素列在镜像后完全一致，1 像素重叠在视觉上完全重合且无任何位移撕裂，彻底封死亚像素采样漏缝。

### 2. 纵向（Y 轴）无缝循环与分层视差约束
- **背景层性质区分**：
  - **地面与山石装饰层**（如 `FarBackground`、`MiddleBackground`）：仅做水平循环，**`repeat_size.y` 必须设为 `0`**；禁止在 Y 轴直接做全屏翻转循环，否则会在角色跳高时将倒挂的山石、地面重复画在半空中。
  - **纯色/渐变天空远景层**（`Sky`）：必须支持垂直方向无缝衔接。
- **天空层垂直镜像闭环**：
  - 天空贴图通常顶部为高光浅色（如浅蓝）、底部为暗调深色。单纯垂直平铺会导致顶部与底部硬拼接（颜色突变跳跃）。
  - **垂直 4 象限闭环方案**：在天空层同时配置 $2 \times 2$ 精灵阵列：
    1. `SkyBase`: `(0, 0)`，无翻转
    2. `SkyBase_HMirror`: `(W - 1, 0)`，`flip_h = true`
    3. `SkyBase_VMirror`: `(0, H - 1)`，`flip_v = true`
    4. `SkyBase_HVMirror`: `(W - 1, H - 1)`，`flip_h = true, flip_v = true`
  - 将天空层的 `Parallax2D.repeat_size` 设为 `Vector2(2 * W - 2, 2 * H - 2)`。这样无论摄像机向正上或正下大范围运动，天空渐变均在上下边界自然镜像折返，形成色彩完全连续、无缝闭合的完整视差循环。
